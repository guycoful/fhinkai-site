# FHINK AI · Day 4 — הפנסיה שלך עובדת בשבילך

נבנה לפי `FHINK_AI_Day4_UX_Brief` + כל ההערות הרוחביות של הלקוח
(סרטונים במסך הראשי: עמרי=דרבון/גיא=שימוש · פופ-אפים משפטיים · שורת הסכמה ·
וובינר עם "כבר נרשמתי ומחכה לזה" · מד מוכנות 25% ליום · שפה אקטיבית · `?pid=`).

## זרימת המסכים (לפי הבריף)

1. **פתיחה** — אותו מבנה כמו כל הימים: "אני רוצה שהפנסיה שלי תעבוד בשבילי",
   ברכה מגדרית, **תזכורת וובינר** (סטריפ "הערב 20:00" לחיץ — הערת הלקוח),
   מסלול עם ימים 1–3 ✓, יום 4 פעיל + "לחץ להתחיל", שני סרטונים, הסכמה משפטית.
   תג Premium בטורקיז (לפי ההאב החי).
2. **מוכנות** — ציטוט באפט ("מישהו יושב בצילם של עצים..."), **15 דקות** (לפי הבריף,
   לא 25), מד מוכנות 25%.
3. **וובינר — הערב!** + "כבר נרשמתי ומחכה לזה".
4. **הפנסיה שלך** (שלב 1/4) — נתוני מסלקה: אחוז הפרשה עובד/מעסיק, סוג קרן,
   דמי ניהול, צבירה נוכחית. שם/גיל/שכר נשאבים (גיל מהשאלון — ראו "פערים" למטה).
5. **סיכום פנסיה** (שלב 2/4) — הצבירה הצפויה בגיל 67, פנסיה חודשית צפויה (צבירה÷200),
   הפרשה חודשית, צבירה נוכחית, שנים עד פרישה, **כמה דמי הניהול עולים לך**
   (שנתי + מצטבר עד פרישה) + תובנת דמי ניהול.
6. **נכסים מול התחייבויות** (שלב 3/4) — שורות דינמיות (סוג + סכום, "הוסף שורה"),
   שווי נקי חי.
7. **סיכום: המרחק לעצמאות כלכלית** (שלב 4/4) — ציר עם 4 תרחישים לפי הסדר בבריף:
   לפני האתגר עם משיכת פיצויים / בלי משיכה / עם קיזוז ה-3% (מודגש — "אתה כאן") /
   **מודל 50/30/20 נעול** (בלור + מנעול, "נפתח לאחר צפייה בוובינר"; `?unlock=1` לבדיקה).
   + תובנת AI, מד מוכנות 100%, בלוק "הערב 20:00".
8. **סיום אתגר / דחייה**.

## הנחות חישוב (data.js → assumptions, להמחשה בלבד)

פרישה 67 · תשואת פנסיה 5% ברוטו (דמי ניהול יורדים ממנה) · מקדם קצבה 200 ·
עצמאות = 25× הוצאות שנתיות (כלל 4%) · תשואת השקעה 7% · משיכת פיצויים ≈ אובדן
מחצית מזרם ההפרשה. הכל בשדה אחד לכוונון של גיא. גילוי נאות מופיע במסכים.

## חיבור נתונים

`fhink_lead_v1` (שם/מגדר) · `fhink_day1_v1` (שכר, הכנסות, הוצאות) ·
`fhink_day2_v1` (הקיזוז → תרחיש "אחרי האתגר") · שמירה: `fhink_day4_v1` ·
API: `/api/day4` (כולל כל התרחישים המחושבים) · `?pid=` נתמך.

## פערים שגיא צריך לסגור

- **גיל**: הבריף מבקש לשאוב מהיום הראשון — הוא נאסף בשאלון הפתיחה, לא ביום 1.
  כרגע דמו (34); לחבר מהשאלון/סופאבייס.
- **שכר ברוטו**: יום 1 אוסף נטו — מוצג כ"השכר החודשי שלך". אם רוצים ברוטו אמיתי,
  להוסיף שדה או לשאוב מהמסלקה.
- פתיחת נעילת 50/30/20 אחרי צפייה אמיתית בוובינר (כרגע `meta.modelUnlocked` / `?unlock=1`).

## בדיקה

```
index.html?screen=pension&reset=1         ← טופס המסלקה (דמו ממולא)
index.html?screen=pensionSummary&reset=1  ← הפנסיה בגיל 67
index.html?screen=networth&reset=1        ← נכסים מול התחייבויות
index.html?screen=summary&reset=1         ← ציר העצמאות (50/30/20 נעול)
index.html?screen=summary&unlock=1        ← עם 50/30/20 פתוח
index.html?name=דנה&gender=נקבה           ← לשון נקבה
```

`ACTIVE_CONSENT` ב-script.js — דגל האישור האקטיבי, כמו בכל הימים.
