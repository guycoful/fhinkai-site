## V3 — סבב פידבק 2 (מבנה הקיזוז החדש)

1. **המותרות קודם**: במסך הקיזוז קבוצת **רצון נפתחת ראשונה**, צורך אחריה,
   **חיסכון לא מוצג בכלל**. הרעיון: לנצח את היום כבר בשלב המותרות.
2. **מיון יורד**: בכל קבוצה הסעיפים מסודרים מההוצאה הגבוהה לנמוכה.
3. **היעד = 3% מסך ההוצאות** (רצון + צורך) — וכל קיזוז נספר, בלי "בונוסים".
4. **זיקוקים בהגעה ליעד** 🎆 — פרץ קונפטי בצבעי המותג + טראקר במצב ניצחון
   + "כל קיזוז נוסף מגדיל את הניצחון" (מדרבן להמשיך). מכבד prefers-reduced-motion.
5. **הסרטונים עברו למסך הראשי** (עמרי = דרבון, גיא = שימוש במערכת); מסך הווידאו
   הנפרד בוטל והשלבים הפנימיים הם עכשיו 1–3.
6. **פופ-אפים משפטיים** (פרטיות + גילוי נאות, נוסח זמני עד עוה"ד) + שורת הסכמה ופוטר.
7. **מד מוכנות 25%** בפיל המוכנות (כל יום = 25%; בסיכום: 50% מצטבר אחרי יומיים).

## זרימת המסכים

1. **פתיחה** — "מתחילים לחסוך", תת-כותרת 3%, ברכה אישית מגדרית, מסלול 4 הימים
   (יום 1 ✓ הושלם, יום 2 פעיל עם "לחץ להתחיל", ימים 3–4 נעולים), **שני סרטונים במסך הראשי**
   (עמרי = דרבון, גיא = שימוש במערכת), CTA "התחל את יום 2" + שורת הסכמה משפטית.
2. **מוכנות** — ציטוט וורן באפט, "רוצה לנצח את היום?...", שאלת 25 הדקות, דחייה נשמרת.
3. **וובינר** — הזמנה + הוספה ליומן + "כבר נרשמתי ומחכה לזה" (בכל יום מהיום השני).
4. **פרטים בסיסיים** (שלב 1/3) — הכל נשאב מיום 1; שלושת הסוגים (רצון במוקד — "כאן מנצחים היום").
5. **קיזוז — לב יום 2** (שלב 2/3) — רצון (מותרות) קודם ופתוח, צורך אחריו, חיסכון לא מוצג;
   סעיפים ממוינים מהגבוה לנמוך; צ'יפים: ללא שינוי / ‎-3%‎ / ‎-5%‎ / ‎-10%‎ / סכום אחר;
   יעד = 3% מסך ההוצאות; הגעה ליעד = זיקוקים + "ניצחת את היום".
6. **סיכום** (שלב 3/3) — חיסכון חודשי/שנתי, עמידה ביעד, תזרים לפני/אחרי, תובנת AI, מד מוכנות.
7. **סיום / דחייה** — כמו ביום 1.

## חיבור נתונים (אוטומטי, בלי לשאול שוב)

## הכרעות עיצוב (לאסף — מסומן "לאסף" בבריף)

- **מיפוי לסוגים ברמת הסעיף**, לא הקטגוריה: סופר=צורך אבל אוכל בחוץ/קפה/משלוחים=רצון; טלפון/אינטרנט=צורך אבל סטרימינג/טלוויזיה=רצון. המיפוי המלא ב-`data.js` וקל לשינוי.
- **בחיסכון לא נוגעים** — שורות נעולות עם תג "שמור"; פנסיה וקרן השתלמות מתויגות "יום 4" (לפי ההערה לגיא).
- **היעד = 3% מסך ההוצאות (רצון+צורך) וכל קיזוז נספר** — עודכן לפי פידבק הלקוח (סבב 2).
- **מספור שלבים פנימי** אוחד ל-שלב 1–4 (25/50/75/100%) בתוך יום 2, באותה תבנית כמו יום 1. הפס העליון של הימים קבוע על "יום 2 מתוך 4" = 50%.
- מסך סיכום נכלל כבר עכשיו (בבריף מסומן "יתווסף בשלב הבא") — באותה רוח של סיכום יום 1, כדי שהמסע ייסגר. קל להסיר אם תרצו.

## מה נשאר לחיבור (פרודקשן)

- סרטונים אמיתיים: שדה `src` בכל אובייקט וידאו ב-`data.js` (כרגע פלייסהולדר במודאל).
- `CONFIG.apiEndpoint = '/api/day2'` ב-`script.js` — ה-POST כולל את כל הבחירות + תוצאות מחושבות.
- מסך הסיכום של הפלטפורמה הקיימת (אם יוחלט להשתמש בו במקום).

## בדיקה מקומית

פותחים את `index.html` בדפדפן (גם file:// עובד — מצב dev לא שולח בקשות).

פרמטרים לבדיקה מהירה:

```
index.html?name=דנה&gender=נקבה     ← פנייה בלשון נקבה
index.html?screen=trim              ← קפיצה ישירה למסך הצמצום
index.html?reset=1                  ← איפוס ה-state של יום 2
index.html?demotrims=1              ← צמצומים לדוגמה (להצגת מצב "היעד הושג" והסיכום)
```
