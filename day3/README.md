# FHINK AI · Day 3 — מגדילים הכנסה (V3)

## V3 — צ'אטבוט המנטור (לפי האפיון של גיא)

- **המסך האחרון של יום 3 הוא הצ'אט**: ממשק בועות שיחה מלא — כותרת עם אווטאר
  ומונה "סבב X מתוך 15", בועות מנטור (ימין, לבן) מול משתמש (שמאל, טורקיז),
  אינדיקטור הקלדה, צ'יפים לתשובה מהירה ושורת קלט חופשי.
- הדמו מריץ תסריט מקוצר (בחירת נתיב + 5 סבבים); **בגרסה החיה גיא מחבר את ה-AI
  האמיתי לאותו ממשק** — עד 15 סבבים. `?screen=chat` לבדיקה, "דלג והצג תוכנית לדוגמה" לקיצור.
- **כרטיס התוכנית** בסוף השיחה: באנר מטרה (שכר היום ← יעד), 3 צעדים ל-30 יום לפי
  הנתיב שנבחר, קצב שבועי, מה שנאמר בשיחה, וגשר ליום 4. נבנה ב-`buildPlan()`.
- תומך `?pid=` (המזהה של גיא מסופאבייס) בכל הימים.

## V2 — וובינר + אישור אקטיבי (פידבק לקוח)

- **חלון הזמנה לוובינר בכל יום מהיום השני**: מסך וובינר (כרטיס תאריך + הוספה ליומן
  Google/Apple) אחרי מסך המוכנות, עם כפתור **"כבר נרשמתי ומחכה לזה"** — מסמן, שומר,
  ומציג צ'יפ "המקום שלך שמור" בכניסות הבאות. פרטי הוובינר ב-`bindCalendarLinks()` ב-script.js.
- **אישור אקטיבי (מוכן, כבוי)**: אם אילת תדרוש — משנים שורה אחת ב-script.js:
  `const ACTIVE_CONSENT = true` ← מופיע צ'קבוקס והכפתור הראשי נעול עד סימון.


יום 3 של אתגר 4 הימים: **הגדלת הכנסה** — נבנה לפי `FHINK_AI_Day3_UX_Brief`
ולפי ההערות הכלליות של הלקוח (סרטונים במסך הראשי, פופ-אפים משפטיים, מד מוכנות 25% ליום).

## זרימת המסכים

1. **פתיחה** — "מגדילים הכנסה", ברכה אישית מגדרית, מסלול 4 הימים (ימים 1–2 ✓ הושלמו,
   יום 3 פעיל עם פולס + "לחץ להתחיל", יום 4 נעול), שני סרטונים במסך הראשי
   (עמרי = דרבון, גיא = שימוש במערכת), CTA "התחל את יום 3" + שורת הסכמה משפטית.
2. **מוכנות** — ציטוט ג'ים רוהן ("לא משלמים לך לפי שעה..."), מוד מסוגלות,
   שאלת 25 הדקות, "כן אני מוכן/מוכנה" / "אעשה את זה בהמשך היום" (מצב נשמר).
3. **קצת עלייך** (שלב 1/2) — השכר נשאב מיום 1 (לא נשאל שוב); שדות חדשים:
   תחום עיסוק (רשימה מורחבת, "אחר" פותח פירוט), שנות ניסיון, יעד שכר חודשי.
   פער חי מוצג תוך כדי הקלדה. שניים בשורה בדסקטופ, אחד במובייל, 52px/14px לפי הבריף.
4. **סיכום** (שלב 2/2) — השכר היום מול היעד, הפער (₪ ו-%), תובנת AI לפי גודל הפער
   + תחום + ניסיון, גשר ליום 2 (אם קיים קיזוז — הוא מוצג כעובד במקביל),
   מד מוכנות 75%, טיזר יום 4. + מסכי סיום/דחייה.

## הכרעות (מסומן "לאסף" בבריף)

- **"יעד שכר חלומי" נוסח מחדש** ל"יעד שכר חודשי" עם הסבר "שאפתני אבל בר-תכנית"
  (לפי ההערה בבריף לשנות את ניסוח ה"חלומי").
- **שכר ברוטו**: הבריף מבקש למשוך ברוטו מיום 1, אבל יום 1 אוסף **נטו** — מוצג
  בתווית מפורשת "נטו, מיום 1". אם רוצים ברוטו, צריך להוסיף שדה ביום 1.
- מסך "קשר" לא קיים (נמחק לפי הבריף). מסך הסיכום נבנה ברוח סיכומי הימים הקודמים.
