# FHINK AI · Day 1 — V4

## V4 — אישור אקטיבי (מוכן, כבוי)

- אם אילת תדרוש אישור אקטיבי — שורה אחת ב-script.js: `const ACTIVE_CONSENT = true`
  ← מופיע צ'קבוקס ("אני מאשר/ת את...") והכפתור "בוא נתחיל" נעול עד סימון.
- ביום 1 אין מסך "כבר נרשמתי" (זו ההרשמה הראשונה); הוא קיים בימים 2–3.


## V3 — סבב פידבק 2

- **תפקידי הסרטונים חודדו**: עמרי = דרבון לעשות את היום עוד לפני שמתחילים; גיא = איך משתמשים במערכת. (התבנית זהה בכל הימים.)
- **מד מוכנות אוחד לסקאלת 25% ליום** (יום 1 = 25%, יום 2 = 50%, יום 3 = 75%, יום 4 = 100%): הפיל במסך המוכנות + המד בסיכום + נקודות הציון.

## V2 — סבב פידבק 1

שלושה שינויים על גבי day1V1:

1. **שני סרטונים במסך הראשי** — עמרי (ההסבר המקצועי, 3:05) + גיא (על המערכת, 2:00),
   נגנים מינימליים עם כותרת ומשך מראש, מצב "נצפה" נשמר. הסרטונים עצמם פלייסהולדר —
   כשיגיעו הקבצים מחברים אותם במודאל הווידאו (`#videoModal` ב-index.html).
2. **שני פופ-אפים משפטיים** — "הסכם הגנת הפרטיות" ו"גילוי נאות — לא ייעוץ".
   נפתחים משורת ההסכמה שמתחת לכפתור הראשי ומקישורי הפוטר.
   **הנוסח הוא זמני ומסומן ככזה** — מחליפים את הפסקאות ב-`#privacyModal` / `#disclaimerModal`
   בנוסח שתספק עוה"ד.
3. **שינוי שם היום** — "ניקוי הערפל" ← "ניקוי הערפל הפיננסי" (כותרת, הדר, מסלול, פוטר).

## בדיקה מהירה

```
index.html?name=דנה&gender=נקבה      ← פנייה בלשון נקבה
index.html?screen=expenses           ← קפיצה למסך מסוים
index.html?popup=privacyModal        ← פתיחת פופ-אפ הפרטיות
index.html?popup=disclaimerModal     ← פתיחת פופ-אפ הגילוי הנאות
index.html?reset=1                   ← איפוס ה-state
```
